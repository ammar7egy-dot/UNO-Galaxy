# 🎮 UNO! Galaxy

> **One Universe. Every UNO.**

UNO! Galaxy is an open-source desktop application built with **Python** and **PySide6** that aims to become the ultimate platform for UNO fans.

The project is designed to support multiple official UNO game variants through a modular game engine, allowing each version to have its own rules while sharing the same core system.

---

## ✨ Planned Features

* 🎴 Multiple UNO variants

  * UNO Classic
  * UNO Flip!
  * UNO Flex!
  * UNO Teams
  * UNO Party!
  * UNO All Wild
  * UNO Show 'Em No Mercy
  * More coming...

* 🧠 Modular game engine

* 🤖 Single-player with AI

* 👥 Local multiplayer

* 🌍 Online multiplayer

* 📚 Complete card collection

* 📖 Rules for every UNO version

* 🏆 Achievements

* 📊 Statistics

* 🎨 Modern desktop interface

* 🔧 Rule & Card Creator (planned)
